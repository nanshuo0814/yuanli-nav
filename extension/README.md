# 源力导航 · 浏览器扩展

Chrome / Edge 扩展，辅助搜索与快速提交收录。

## 功能

- 弹窗搜索：跳转到源力导航并带 `?q=` 参数
- **收录当前页**：用当前标签页标题和 URL 预填 GitHub Issue
- 右键菜单：**收录到源力导航**

## 安装（开发者模式）

1. 打开 `chrome://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录 `extension/`

## 配置

如需修改站点地址，编辑 `popup.js` 中的 `SITE` 常量。

## 图标

`manifest.json` 引用 `icon128.png`。可自行放置 128×128 PNG，或临时移除 `icons` 字段进行本地调试。
